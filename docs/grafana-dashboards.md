# Grafana dashboards

Grafana Operator syncs `GrafanaDashboard` resources from each app's `dashboards/` directory. The [Grafana Helm release](../flux/bastille/apps/observability/grafana/app/helmrelease.yaml) manages the server, login, data sources, and storage. Dashboards use pinned upstream references where possible, with local JSON or Jsonnet for corrections or unavailable sources. The [VolSync dashboard](../flux/bastille/apps/storage/volsync/dashboards/grafanadashboard.yaml) is a small example. Git is the source of truth; UI edits can be overwritten.

Stable dashboard UIDs preserve links; deleting a resource deletes its dashboard. Data source mappings use `prometheus` and `loki`, but do not fix hard-coded upstream UIDs. Flux substitution is disabled on local dashboard content to preserve Grafana variables. Exports can contain cached query results and local selections unsuitable for this public repo. The empty file providers release old provisioning ownership without deleting dashboards and support restores of older backups. Re-enabling the dashboard sidecar would put it in competition with the operator. The resource's `DashboardSynchronized` condition reports sync failures.
